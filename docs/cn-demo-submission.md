# CN 演示版提交说明（2026-10-16）

本项目定位为本机运行的 GIS 演示工作台。使用 `start.bat` 或桌面启动器时固定为 `cn` 模式，并仅监听 `127.0.0.1`。

## 启动与演示

1. 先关闭旧后端，再运行 `start.bat`。启动器会拒绝复用区域配置不匹配的旧服务。
2. 已安装依赖的环境可直接启动；新机器先安装 `backend/requirements.txt`。依赖安装和地图加载需要联网，离线环境需预装依赖并准备本地数据。
3. 在设置中配置演示者自己的 DeepSeek 或智谱密钥。提交包不包含私人密钥。
4. 推荐演示：上传小型 GeoJSON/CSV → 图层显示 → 缓冲/面积/筛选 → AI 解读已有数据 → 保存及导出工程。
5. 不把 OSM 在线路网、Open-Meteo 天气、USGS 地震或境外卫星源列入演示流程。相关能力在 CN 模式禁用；高程数据建议准备本地 GeoTIFF。

## 提交包

运行 `python scripts/package_cn_demo.py`，产物位于 `output/GIS-WORKTABLE-CN-demo-2026-10-16.zip`。

打包按 Git 源文件清单收集当前修改及未提交源码，不包含 `.git`、开发缓存、个人会话、凭据、日志、运行输出、虚拟环境或 node_modules。无需把本机整个项目目录直接压缩。包内服务目录数据库为新建的白名单副本；原始数据库不变，工作区事实数据库不带入。

这个包是源码演示包，不是已包含 Python/GIS 依赖的免安装程序。换机器须提前安装依赖并验证启动。高德/天地图与模型服务的可用性仍受现场网络、配额及凭据影响。

## 本轮修复的提交风险

- CN URL 代理绕过和境外模型预设；数据与模型请求分别检查目标地址。
- 输出文件、上传文件名、工程 ID 与 blob 路径越界。
- ZIP 不安全路径、符号链接和过大的解压内容；上传限制为 100MB。
- 整个 cache 目录公开，改为仅公开图表目录。
- 任意网页跨域访问本机 API，以及异常 Host 请求。
- 聊天/导入历史中的不可信 HTML，仅保留展示标签、安全链接和本机图件。
- 补齐文件上传、凭据加密、网页解析、模型 HTTP 与 GeoParquet 读取的直接依赖声明，使用本机已验证版本。

## 验证记录

相关测试累计 255 项通过，4 项境外样例测试因 CN 策略跳过；正常工程导出/导入回归通过。独立端口新版服务的首页及 CN 健康检查正常，聊天 HTML 注入样例没有执行，正常 Markdown 保留。提交包完成 ZIP 校验、敏感目录排除、数据库完整性检查及解压后启动检查，演示服务目录包含 92 项白名单服务。

## 仍需理解的边界

这是本地演示项目，未增加面向公网或多人使用的账号认证及完整权限隔离。不要将服务改为公网监听。操作系统出站限制、第三方原生库、代理和数据授权等仍不由应用入口策略完全覆盖。模型白名单也不等于提供商部署位置或数据处理合规认证。

本轮做的是代码与配置风险排查、针对性测试和本地冒烟验证，不是全面渗透测试或法律合规认证；没有为临交付更换整个依赖栈。
